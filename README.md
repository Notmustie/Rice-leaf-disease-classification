# Rice-leaf-disease-classification
Reproducible deep learning pipeline for rice leaf disease classification, featuring robust data deduplication, stratified dataset management, confidence-aware inference, and fair performance comparison between a custom CNN and EfficientNet. Designed for research transparency, methodological rigor, and deployment-ready analytics integration.

This repository implements a reproducible deep learning pipeline for rice leaf disease classification.
It focuses on dataset integrity, fair model comparison, and confidence-aware inference.

## Methodological Contributions
- Dataset validation and stratified splitting
- Duplicate image detection and removal
- Custom CNN and EfficientNet comparison under identical evaluation conditions
- Confidence-based rejection of uncertain predictions

## Pipeline Overview
1. Dataset preparation and validation
2. Duplicate detection and removal
3. Stratified train/test/predict split
4. Model training (Custom CNN, EfficientNet)
5. Evaluation and comparison
6. Inference with confidence thresholding
7. Export of results for visualization
